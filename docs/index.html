项目简介

QtCAE-QuickGear 是一套面向齿轮传动的轻量化 CAE 仿真工具：C++ / Qt 原生实现， 搭配 AI 辅助网格生成，对中小模数齿轮做快速应力与变形评估，支持 STL 几何导入。

本仓库为开源壳工程：包含演示网页、Qt 基础界面壳与交互框架。 核心求解逻辑不开源，以加密静态库形式交付。

因此本页面只是轻量预览 Demo：3D 视图与云图为演示效果， 用来快速感受工具形态，不承担高精度求解职责。
