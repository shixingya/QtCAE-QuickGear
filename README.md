# QtCAE-QuickGear

> 基于 Qt + C++ 的轻量化齿轮 CAE 仿真工具，集成 AI 辅助网格生成。
> 面向中小零部件工程师与小机械厂的"够用就好"型齿轮应力快速评估方案。

## 这是什么

QtCAE-QuickGear 把"算一轮齿轮应力"这件事压缩到几分钟：导入齿轮几何（或直接用参数化齿轮副），
一键完成网格划分与静力求解，直接看齿面接触与齿根弯曲的应力云图。

它不追求替代 Ansys / Abaqus / Romax，只解决一个具体问题：
**中小批量、单件非标齿轮，想快速判断"这个齿轮扛不扛得住"，却不想为一次校核搭一套昂贵的商用 CAE。**

核心特点：

- **Qt 原生客户端**：C++ / Qt 实现，Windows 单机运行，无需装求解器环境、无需 License Server
- **AI 辅助网格生成**：按齿形特征自动布置齿根与接触区网格密度，减少手工调网格的时间
- **齿轮专用流程**：参数化齿轮副（模数 / 齿数 / 扭矩）或 STL 几何导入，直接出结果
- **可交付的结果**：峰值等效应力、最大位移、单元规模、安全系数与云图
- **能交出去的结论页**：一键导出单页 A4 PDF（结论句 + 参数表 + 云图 + 免责声明）或云图 PNG
- **能卖得出去的授权**：离线授权文件绑定机器码，Ed25519 公钥签名（客户端只带公钥，拆开也签不出），台账批量签发 + 到期提醒与续费审计
- **能接着干活**：工程存成 `.qgpj`，下次打开连参数、几何与上次结果一起回来

## 在线演示（网页版）

`docs/index.html` 是一个纯前端单页演示，部署在 GitHub Pages：
**https://shixingya.github.io/QtCAE-QuickGear/**

页面上能做的事：

- 拖拽旋转 / 滚轮缩放查看齿轮副 3D 模型
- 调整齿数、模数、输入扭矩，运行"预览仿真"，查看示意应力云图与结果面板
- 一键复制本机设备码

> ⚠️ 网页端只是**交互形态预览**：云图由顶点距离场着色生成，数值由参数估算，
> **不是真实有限元求解结果**。真实求解在 Qt 本地客户端中完成。

## 本地跑演示页

无需构建、无需依赖安装，三种方式任选：

```bash
# 方式一：直接双击 docs/index.html
# 方式二：起一个静态服务（推荐，避免个别浏览器的 file:// 限制）
cd docs
python -m http.server 8000
# 打开 http://127.0.0.1:8000
```

```bash
# 方式三：任意静态服务器
npx serve docs
```

依赖通过 CDN 动态加载，带多源兜底（`npmmirror → jsdelivr → unpkg → esm.sh`），
任一源不可达会自动切换；three.js 全部不可用时仅 3D 区域降级提示，试用额度等功能不受影响。

### 部署到 GitHub Pages

1. 仓库 **Settings → Pages**
2. Source 选择 **Deploy from a branch**
3. Branch 选 `main`，目录选 **/docs**，保存
4. 约 1 分钟后访问 `https://shixingya.github.io/QtCAE-QuickGear/`

## 获取本地 Qt 客户端

网页演示次数用完后会弹出设备码，流程如下：

1. 复制页面上的设备码
2. 通过 [Issues](https://github.com/shixingya/QtCAE-QuickGear/issues) 或下方联系方式联系开发者，说明使用场景（齿轮类型、模数范围、批量需求）
3. 获取 Qt 本地客户端安装包
4. 客户端内「授权 → 激活 / 查看机器码…」显示本机机器码，把它发给开发者签发授权
5. 导入 `license.qglic` 授权文件，客户端离线校验（机器码 + 有效期 + 签名），无需联网

> 注意：网页显示的是**浏览器设备码**，客户端显示的是**本机机器码**（硬件信息派生），
> 两者是不同标识 —— 浏览器拿不到本机硬件信息。**激活以客户端机器码为准**，
> 网页设备码用于沟通与问题定位。

## 适合谁用

- 中小零部件工程师：单件、小批量的非标齿轮，需要快速判断强度够不够
- 小型机械加工厂 / 齿轮作坊：客户给图问"这个能不能做、能用多久"，需要现场出个结论
- 教学与方案阶段：需要直观的应力云图辅助讲解，而不是一张密密麻麻的求解日志

**不适合**：需要规范认证、需要多物理场耦合、需要疲劳寿命谱分析、需要出具第三方检测报告的场景。

## 仓库结构

```text
QtCAE-QuickGear/
├─ docs/
│  ├─ index.html        # 开源演示页（GitHub Pages 源目录，单文件、纯前端）
│  └─ webcheck.js       # 网页端口径体检（node docs/webcheck.js，发布前跑一次）
├─ src/                 # 开源 Qt 壳工程（Qt5/Qt6 + CMake）
│  ├─ CMakeLists.txt
│  ├─ main.cpp
│  ├─ app/              # 主窗口 / 参数面板 / 云图视图 / 结论页导出 / 激活对话框 / 求解线程
│  ├─ core/             # 参数模型 / 求解后端接口 / 示意后端 / STL 读取 / 工程文件 / 授权与 Ed25519（编为 qgcore 库）
│  ├─ tools/            # qglicense：授权签发、密钥生成与校验；qgselftest：冒烟自检（均不随安装包发行）
│  └─ README.md         # 构建方式、免安装包、闭源库接入、授权签发与文件格式
├─ tools/
│  └─ pack.ps1          # 免安装包打包（版本校验 + 固定 DLL 清单 + 使用说明 + zip）
├─ .gitignore           # 已屏蔽 build/、dist/、src/private/（闭源库目录）
└─ README.md
```

壳工程无需闭源库即可编译运行（内置示意后端），详见 [src/README.md](src/README.md)。

## 路线图

- [x] 演示页：3D 预览 + 每日 10 次试用 + 设备码引导
- [x] Qt 壳工程开源（主窗口、参数面板、云图视图、求解线程、激活对话框）
- [x] 客户端激活链路：机器码生成 + 授权文件签名 / 验签 / 导入
- [x] 授权签发工具 `qglicense`（machine / keygen / pubkey / issue / batch / renew / audit / verify / install）
- [x] 免安装包（手工部署，干净 PATH 可直接启动）
- [x] exe 版本资源（右键属性可查版本号，与 `project(VERSION)` 同源）
- [x] STL 导入（二进制 / ASCII）+ 未求解时的几何投影预览
- [x] STL 容错：尾部填充、截断、残缺 facet 都给准确原因；封闭性检测决定体积是否可报
- [x] 结果导出：云图 PNG / 单页 A4 结论 PDF（未授权自动加水印）
- [x] 导出不会假成功：目标 PDF 开在阅读器里时明确报错并保留旧文件（先写 `.part` 再换名）
- [x] 报告字体按“装了且能画汉字”挑候选，不赌某一台机器装了雅黑
- [x] 工程文件参数读取即夹回合法区间，逐条写日志；几何文件丢了降级不冒充
- [x] 工程文件里的结果要和参数对得上：峰值取逐齿最大值与自报峰值中较大的那个、n 按“许用 / σv”重算，
  逐齿数组与齿数对不上时按无结果打开，不会交出一张“图上一片最红、指标栏写 n=9.52 通过”的结论页
- [x] 求解中关窗口不会拆掉正在跑的后端（等算完再退）
- [x] 求解进行中不能换工程/换几何（菜单置灰 + 拖放也拒），不会出现“新参数 + 旧结果”
- [x] 窗口位置会校对屏幕：外接屏拔掉后不再把窗口留在空气里
- [x] 材料口径单一来源：下拉 / 工程文件校验 / 许用应力表共用一张表，表外牌号不静默套默认值
- [x] 改主动轮齿数不再偷偷夹小从动轮（z₂ 只受区间约束，增速传动也合法）；读取工程时也不再按 z₁/2 夹取，界面上刚放开的数不会一存一读就没了
- [x] 参数进界面不被小数位悄悄四舍五入：模数 / 齿宽到 0.01 mm、扭矩到 0.1 N·m，
  装不下的值在日志里说“已按显示值计算”
- [x] 结论 PDF 写出材料许用应力，客户能自己核 n = 许用 / σv
- [x] 峰值超出云图色标量程（固定 320）时明说：色标顶端写 `≥320`、图内橙色提示带、报告量表行同步
- [x] 导入授权时比一次到期日：已过期的、比现有更短的、拿有限期换永久的都拒绝，
  不会因为点错旧邮件附件把手上那张更长的授权顶掉
- [x] 工程文件 `.qgpj` + 拖放打开 + 最近文件 + 求解日志面板
- [x] `qgselftest` 冒烟自检（76 项，含 Ed25519 RFC 8032 官方向量、续费门禁、PDF 单页、渲染覆盖率、授权到期与批量签发、STL 封闭性与网页/客户端公式口径断言、导出失败路径与工程文件夹取、授权降级导入拦截、增速传动工程读写一致、结果与参数一致性）
- [x] 网页端与客户端同一套数值口径（`docs/webcheck.js` 直接在沙箱里跑页面脚本对账）
- [x] 签名升级为 Ed25519 公钥验签（客户端只带公钥，旧 HMAC 授权仍可验）
- [x] 授权经营链路：台账批量签发 + 交付单、一键续费（`renew`）、客户端到期徽标与提醒、`qglicense audit` 续费审计
- [ ] 授权在线自助续期（当前为离线人工签发）
- [ ] 闭源求解器接入（`-DQTG_USE_CLOSED_SOLVER=ON`）
- [ ] 三维云图渲染（OpenGL / VTK 替换当前 2D 示意视图）
- [ ] 导入几何参与求解（网格修复 / 实体化，目前仅预览）
